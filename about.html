About the project

About Fake Account Detector

Detect Fake Social Media Accounts Using Machine Learning

Problem statement

Fake accounts are used for spam, scams, harassment and for inflating follower counts. Checking accounts by hand does not scale. This project explores how a machine learning model can use a handful of public account details to estimate whether an account is likely to be fake or genuine.

How it works

  1. You enter account details in the form.
  2. The app validates them and calculates extra features (ratios and rates).
  3. A Random Forest model, saved with Joblib, estimates the probability that the account is fake.
  4. The result page shows the prediction, probability, indicators and an explanation.

Dataset (synthetic)

No real social media data is used. The training data is synthetic: generated by a Python script that mixes several account types (regular users, casual users, popular users, spam bots, accounts with bought followers, and clones). About 3% of the labels are flipped on purpose so the data is not unrealistically clean.

Scores measured on synthetic data do not represent real-world detection accuracy. To measure real performance, retrain the model on a properly labelled real dataset.

Features used (14)

  • Number of followers
  • Number of following
  • Number of posts
  • Account age (days)
  • Profile picture available
  • Bio available
  • Username length
  • Digits in username
  • Average likes per post
  • Average comments per post
  • Followers-to-following ratio
  • Posts per day
  • Engagement rate
  • Digit share of username

Limitations

  • The model learned from synthetic data, so it may not match real platforms.
  • It only sees the numbers you type in, not photos, posts, or account networks.
  • Genuine accounts with unusual behaviour can be flagged by mistake (false positives).
  • Clever fake accounts that look normal can be missed (false negatives).

Responsible use

A prediction is an estimate, not proof. Please do not use this tool alone to accuse, harass, or take action against any real person or account. Any real moderation decision should involve a human reviewer.

The app stores analyses only in memory while it runs. Nothing is saved to disk or sent anywhere else.
